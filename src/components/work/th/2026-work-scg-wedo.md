- ทำงานร่วมกับ Lead และ Manager เพื่อปรับปรุงกระบวนการทำงาน พัฒนาเครื่องมือ และเพิ่มประสิทธิภาพการทำงานของทีม Developer
- สนับสนุนการพัฒนาศักยภาพบุคลากรในองค์กร ทั้งด้านเทคนิค แนวทางการทำงาน และมาตรฐานการพัฒนา
- ติดตาม วิเคราะห์ และสื่อสารข้อมูลสำคัญด้าน Security หรือประเด็นเทคโนโลยีที่ส่งผลกระทบต่อระบบ เพื่อให้ทีมรับมือและแก้ไขได้อย่างรวดเร็ว
- ร่วมตรวจสอบและปรับปรุงระบบ กระบวนการ และ Workflow เพื่อยกระดับคุณภาพ ความเสถียร และประสิทธิภาพของงาน
