- พัฒนา API ของ `DAAS` ด้วย `Go` ออกแบบฐานข้อมูล `Azure PostgreSQL` และวางสถาปัตยกรรม Kubernetes บน `Azure Kubernetes Service` (AKS)
- ออกแบบระบบ ETL ของ `DAAS` ใหม่เพื่อเพิ่มประสิทธิภาพและรองรับข้อมูล **200 GB** พร้อมย้ายเวิร์กโฟลว์จาก `Talend BigData Community Edition` ไปยังระบบ ETL ที่พัฒนาด้วย `Go`
- พัฒนา `PPE-API` ให้รองรับได้ถึง **1,000 คำขอต่อวินาที** พร้อมตั้งค่าโครงสร้างพื้นฐาน Kubernetes และระบบอัตโนมัติแบบ zero-downtime
- ออกแบบและพัฒนาฐานข้อมูล หน้าจอผู้ใช้ และ API ของ `Notice-Subscriber`
- พัฒนา API ระบบตรวจสอบสถานะ การบันทึก log งานตามกำหนดเวลา และรายงานอัตโนมัติใน `Notice-Manager`
- พัฒนา `GWP` เครื่องมือตั้งค่าโปรโมชัน พร้อมตั้งค่าโครงสร้างพื้นฐาน Kubernetes
