- นำแนวทาง Agile และ `GitLab` มาใช้ในการทำงานร่วมกัน พร้อมตั้งค่า `GitLab Runner` สำหรับ CI/CD บน Windows Server และ Linux
- ฝึกอบรมทีมวิศวกรระบบให้ติดตั้ง ตั้งค่า และใช้งาน `Kubernetes`, `MongoDB` และ `Redis`
- พัฒนา API ระบบตรวจสอบสถานะ การบันทึก log งานตามกำหนดเวลา และรายงานอัตโนมัติใน `LINE-BOT` พร้อมรายงานผลสำรวจผ่านเว็บ
- สร้าง `DevOps-UI` ให้ทีม QA Support ใช้ตั้งค่าและดูแลซอฟต์แวร์
- พัฒนาฟีเจอร์แลกรับสินค้า ประมวลผลวิธีชำระเงิน (tender) และรับชำระเงินใน `POSCMG` รวมถึงฟีเจอร์การจองใน `SPACMG` พร้อมดูแลและแก้ไขปัญหาของทั้งสองระบบ
- สร้าง Windows service `TransferInboundFTP` สำหรับโอนย้ายไฟล์ระหว่างเซิร์ฟเวอร์ FTP
- ให้คำปรึกษาด้าน REST API สำหรับบัตรของขวัญบนมือถือและบริการบัตรของขวัญ `Ogloba Webservice`
